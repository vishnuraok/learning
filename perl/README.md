# Perl Learning Project

Welcome to the Perl Learning Project! This repository is dedicated to learning and experimenting with the Perl programming language.

## Project Structure

The directory contains scripts, examples, and exercises to help you understand and practice Perl.

## Prerequisites

- Perl installed on your system. You can check by running:
    ```bash
    perl -v
    ```
- A text editor or IDE of your choice.

## How to Use

1. Clone the repository:
     ```bash
     git clone git@github.com:vishnuraok/learning.git
     ```
2. Navigate to the project directory:
     ```bash
     cd learning/perl
     ```
3. Run the Perl scripts:
     ```bash
     perl script_name.pl
     ```
